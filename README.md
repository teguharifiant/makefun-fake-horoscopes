A deterministic program that writes one fake horoscope for the Muse
model family — 185 characters — to `/output/entry.txt`.

## The entry

> Muse: Mercury retrogrades into your context window this week. Your lucky prompt is the one you deleted at 3 a.m. Skip Friday's deploy — the evals are watching, and they brought friends.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18 or later. No dependencies, no network, no input:
the same text is written on every run.
